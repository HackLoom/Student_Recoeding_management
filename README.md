# Student Record Management System

## Project Overview
The Student Record Management System is a Python-based application designed to manage student information efficiently. It allows users to add, search, update, delete, and display student records through a simple menu-driven interface.

## Features
- Add new student records
- Search students using roll numbers
- Update existing student details
- Delete student records with confirmation
- Display all students in ascending order of roll number
- Input validation to prevent incorrect entries
- Prevent duplicate roll numbers
- Store and retrieve student records using JSON file handling

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Open the terminal.
5. Run the following command:

```bash
python stud_mang.py
```
